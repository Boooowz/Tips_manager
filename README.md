# 💰 Tips Manager

> Διαχείριση παρουσιών και διαμοιρασμού φιλοδωρημάτων για εστιατόρια και μπαρ. Standalone HTML εφαρμογή με τοπική αποθήκευση.

**🎯 [Live Preview](https://boooowz.github.io/Tips_manager/)** — Δοκίμασε αμέσως χωρίς installation!

---

## 📖 Περιγραφή

Εργαλείο για ιδιοκτήτες/διαχειριστές εστιατορίων που χρειάζο��ται:

- Καταγραφή ημερήσιων παρουσιών εργαζομένων (ΝΑΙ/ΟΧΙ ανά ημέρα)
- Δίκαιο διαμοιρασμό φιλοδωρημάτων με βάση **μονάδες αξίας** (π.χ. μάστορας 1.5, βοηθός 1)
- Ιστορικό όλων των μηνών και ετών
- Σύνοψη ανά εργαζόμενο και ετήσια επισκόπηση

## ✨ Χαρακτηριστικά

- 🗓 **Πολλαπλοί μήνες/έτη** — όλα τα δεδομένα αποθηκευμένα μόνιμα
- 👥 **Έως 100 εργαζόμενοι** με σταθερά ονόματα και μονάδες
- ⚖️ **Σταθμισμένος διαμοιρασμός** — μάστορες και βοηθοί παίρνουν αναλογικά
- 📊 **Ετήσια επισκόπηση** για όλους τους μήνες
- 💾 **Backup/Restore** σε JSON
- 📈 **CSV Export** ανά μήνα για Excel
- 🌙 **Dark theme** φιλικό στα μάτια
- 🔒 **100% τοπικό** — όλα τα δεδομένα μένουν στον browser σου
- 📱 **Responsive** για mobile και desktop

## 🧮 Πώς δουλεύει ο διαμοιρασμός

Παράδειγμα: 5 εργαζόμενοι, οι 3 δούλεψαν μια ημέρα, με 90€ φιλοδωρήματα.

| Εργαζόμενος | Δούλεψε | Μονάδες/μέρα |
|---|---|---|
| Νίκος (μάστορας) | ✓ | 1.5 |
| Γιάννης (βοηθός) | ✓ | 1.0 |
| Μαρία (βοηθός) | ✓ | 1.0 |
| Έλενα | ✗ | 1.0 |
| Πέτρος | ✗ | 1.0 |

**Υπολογισμός:**
- Συνολικές μονάδες ημέρας = 1.5 + 1.0 + 1.0 = **3.5 μονάδες**
- Αξία ανά μονάδα = 90€ ÷ 3.5 = **25.71€/μονάδα**
- Νίκος = 1.5 × 25.71 = **38.57€**
- Γιάννης = 1.0 × 25.71 = **25.71€**
- Μαρία = 1.0 × 25.71 = **25.71€**

**Σύνολο διαμοιρασμού = 90€** ✓

## 🛠 Τεχνικά

- **Pure HTML/CSS/JavaScript** — καμία εξωτερική βιβλιοθήκη
- **localStorage** για persistence
- **Single file** — όλα σε ένα `index.html`
- **Offline-first** — δουλεύει χωρίς internet

## 💾 Backup & Ασφάλεια

Τα δεδομένα αποθηκεύονται **τοπικά στον browser σου** (localStorage). Για ασφάλεια:

- **⬇ Backup** → JSON αρχείο με όλα τα δεδομένα
- **⬆ Restore** → επαναφορά από JSON
- **📊 CSV** → εξαγωγή τρέχοντος μήνα για Excel

Συνιστάται εβδομαδιαίο backup σε cloud (Google Drive, Dropbox).
